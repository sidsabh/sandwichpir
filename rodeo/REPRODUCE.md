# Reproducing the evaluation

Every table and figure in the paper is backed by a data file (submitted with
the paper source under `data/`), generated by a runner or sweep driver in this
repository. The table below maps each paper element to its data file and
generator.

## Setup

```
git clone --recursive <this repo> && cd rodeo
make schemes            # init + patch baseline submodules (patches/ only)
```

Instances (us-west-2 on-demand): `r7i.2xlarge` for CPU baselines,
`g6e.xlarge` for single-GPU, `g6e.2xlarge` where noted (host DRAM),
`g6e.48xlarge` for multi-GPU, `m6a.xlarge` for client timings.

## Paper -> data -> generator

| Paper element | Data file (`data/`) | Generator (this repo) | Instance |
|---|---|---|---|
| PIR comparison (`tab:birds-eye`, `tab:birds-eye-full`) | `table1_birds_eye.csv` | `runners/run_{hintlesspir,ypir_sp,inspire,kspir,distpir,sandwichpir}.py`; `run-overnight.sh` | r7i / g6e.xlarge |
| Batching figure (`fig:batching`) | `batching_tput_l40s.csv` | `target/release/run <items> <bits> <B>` (SandwichPIR series); `sweeps/dist_reshape.sh` (SimplePIR-GPU series) | g6e.xlarge |
| Record-size sweep (`tab:record-shape`) | `record_shape_l40s.csv` | `sweeps/record_shape.sh` | g6e.xlarge |
| Multi-GPU scaling (`tab:mgpu`) | `mgpu_grid_l40s.csv` | `sweeps/mgpu_grid.sh` (`MULTI_GPU=8`) | g6e.48xlarge |
| Microbenchmarks (`fig:impl-breakdown`) | `impl_breakdown_l40s.csv` | `VERBOSE=1 target/release/run` | g6e.xlarge |
| Offline preprocessing (`tab:offline-l40s`) | `offline_client_32k_l40s.csv` | `sweeps/offline_split.sh` (stage prints in stdout) | g6e.xlarge |
| Client costs (`tab:client-l40s`) | `offline_client_32k_l40s.csv` | `sweeps/offline_split.sh` (client fields; host CPU is the functional equivalent of an m6a.xlarge) | g6e.xlarge |
| GPU specifications (`tab:gpu-specs`) | none (NVIDIA datasheets + AWS pricing) | -- | -- |
| Lattice parameters (`tab:params`) | none | `scripts/estimator_wrapper.py` (security); `scripts/noise_bounds.py` (correctness + moduli selection) | any |
| Wikipedia batching and latency (`sec:wikipedia`, `fig:wiki-latency`) | `wiki_batch_l40s.csv`, `wiki_latency.csv` | `sweeps/wiki_batch.sh`; client on the g6e host CPU (m6a.xlarge equivalent); Ookla medians | g6e.xlarge |
| STREAM bandwidth (hardware appendix) | `stream_r7i.csv` | `sweeps/run_stream.sh` | r7i.2xlarge |
| DistPIR CPU rows (`tab:birds-eye`) | `table1_birds_eye.csv` | `sweeps/distpir_cpu.sh` (p=256 convention), `sweeps/distpir_native.sh` | r7i.2xlarge |
| PIRonGPU rows (`tab:birds-eye`) | `table1_birds_eye.csv` | `sweeps/pirongpu_bench.cu` (build PIRonGPU + HEonGPU v1.1.0 per its README, add as example target) | g6e.xlarge |
| KsPIR rows (`tab:birds-eye`) | `table1_birds_eye.csv` | `runners/run_kspir.py` + `patches/10-kspir-size-arg.patch` (`sweeps/kspir_setup.sh` bootstraps HEXL/clang) | r7i.2xlarge |
| HintlessPIR rows | `table1_birds_eye.csv` | `runners/run_hintlesspir.py` (LinPIR `rows_per_block=2048` default; artifact default 1024) | r7i.2xlarge |

Shapes and per-scheme CLI conventions are documented in `configs/shapes.md`.
